Roadmap

Where FileManagerUltra is heading. These are plans, not promises: order and scope can change, and there are no dates. Ideas and bug reports are welcome as GitHub issues.

Last updated 13 November 2026, after release 0.2.1.

Next release Now Next Later

Ready for the next release Next release

Already done on main and waiting for the next release. The changelog has the full list.

SVG preview

SVG files show as pictures in Preview, text included, with Fit and 100% and a choice of background behind transparent parts. Turn Preview off to read the source.

SVG thumbnails

SVG drawings, including compressed .svgz files, show as pictures in folder thumbnails.

Easier file type settings

Preferences ▸ Preview ▸ File types lists the types on the left and their filename patterns on the right, editable in place and with the keyboard.

Safer SVG images

An SVG can no longer make the app read other files from your computer through image references.

Now: finishing the 0.2 beta

Making the current release solid on every platform, and closing the gaps left in the Media pane.

Windows and macOS checks

Hands-on testing of live folder refresh (including mapped network drives), USB and VeraCrypt devices, the ffmpeg download on Windows and the installed Windows shortcut icon.

Signed installers

Code-signed Windows installers and notarized macOS builds, so the OS stops warning on first start. Certificates cost money every year: sponsoring helps.

Picture-based subtitles

Show the image subtitles found on DVDs and Blu-ray discs (VobSub and PGS) in the Media pane. Text subtitles already work.

Hardware video decoding

Let the graphics card decode video where it can, falling back to software decoding when it can't.

Fixes for what you report

Bugs reported by early users come first. Report an issue.

Next

The features planned after that.

File permissions

View and change permissions and ownership (chmod/chown on Linux and macOS, basic ACLs on Windows), recursively if you like, with a clear explanation when a change is denied. Works on SFTP where the server allows it.

Text and Markdown editor

Edit in a pane with save, undo/redo, find and replace, syntax highlighting and a live Markdown preview. Saving never loses data on failure, and you are warned when the file changed on disk. Works on remote files too.

Better search

Building on Find Files: regular expressions, include and exclude filters, search on SFTP and SMB, results that open at the matching line, and search and replace across files.

Later

Wanted, but not scheduled yet.

Batch rename

Rename many files at once with numbering, text replacement and case changes, a before/after preview, and safe handling of collisions and swaps.

Folder synchronization

Compare two folders, review a plan of copies, updates and deletions before anything changes, then run it: one-way, mirror or two-way, with saved folder pairs.

Archives

Browse zip and tar archives as folders and extract from them.

Restore layout: yes, no or ask

Choose whether the previous pane layout comes back at startup, or have the app ask each time.

Automation

A command line and control channel on top of the app's command registry, so scripts and tools can drive it.

Plugins

Extend the file manager with your own additions.

What stays the same

Never crash

Failures become clear errors you can act on.

Never block

Disk and network work runs in the background, so the window always responds.

Security is tested

No secrets on disk, and every input is treated as hostile.
