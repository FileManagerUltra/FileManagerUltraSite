Install

Installers are attached to each GitHub Release. Download the file for your system from the latest release.

Installers are not signed yet

The installers are not code-signed or certified: there is no Windows code-signing certificate and no Apple notarization yet. Windows SmartScreen and macOS Gatekeeper will warn you on first start; the steps below show how to continue. Download only from the GitHub Releases page.

Signing certificates cost money every year. If you'd like to help make signed installers happen, sponsor FileManagerUltra on GitHub. Donations are very welcome.

Windows (x64)

  1. Run the *-setup.exe.
  2. If SmartScreen appears, choose More info → Run anyway.

macOS (Apple silicon)

  1. Clear the quarantine flag, open the .dmg and drag the app to Applications.
  2. On first start, right-click the app and choose Open.
xattr -d com.apple.quarantine ~/Downloads/FileManagerUltra_*.dmg

Linux (x64)

Debian / Ubuntu:

sudo apt install ./filemanagerultra_*.deb

apt also installs the ALSA sound library if it is missing.

Any distro (needs FUSE 2 and the ALSA sound library, present on desktop installs):

chmod +x filemanagerultra_*.AppImage
./filemanagerultra_*.AppImage

From source

With the Rust toolchain installed (on Linux, also pkg-config and the ALSA headers, e.g. sudo apt install pkg-config libasound2-dev):

cargo build --release --locked -p fm-app
./target/release/filemanagerultra

The app checks GitHub Releases for newer versions at startup. This can be turned off in Preferences, and updating is always manual. See the full install guide.

Video and ffmpeg

The Media pane and video previews use ffmpeg for video, chapters and poster frames, and for audio formats the built-in decoder can't read. Plain audio such as MP3 and FLAC plays without it. ffmpeg is not bundled; a copy already on your computer is always used first.

Windows

Open Preferences ▸ Media and download ffmpeg there, or accept the offer when a video can't play. The download is a pinned version, checked against a built-in SHA-256 checksum before it is installed.

Linux and macOS

Install ffmpeg with your package manager. Preferences ▸ Media shows whether it was found.

Debian / Ubuntu:

sudo apt install ffmpeg

macOS (Homebrew):

brew install ffmpeg

Status

FileManagerUltra is in beta (latest release 0.2.1): core features work, but expect rough edges and changes between releases. Features marked Next release are on main and not in a release yet. Work is planned and tracked with OpenSpec. Follow along, report issues or contribute on GitHub.
