Synchronize folders, and see every change first

FileManagerUltra compares two folders on your computer, a network share (SMB) or an SFTP server, shows exactly what it would copy or delete, and changes nothing until you press Start. Update a backup, mirror a folder, or merge two copies both ways, from the same app you browse your files in.

Any two folders

Local drives, USB disks, mounted shares, in-app SMB and SFTP, in any combination: a laptop folder to a NAS, a server to a backup disk.

Review before anything happens

Compare lists every copy, overwrite and delete in a folder tree. Change any item's action, or leave it out, then synchronize.

Three goals

Update copies new and changed files, Mirror makes an exact copy, Two-way merges changes in both directions and leaves conflicts to you.

Keep in sync

Optionally keeps watching while the app is open and applies later changes for you. Conflicts and deletes still wait for your review.

A guided setup that asks plain questions

Highlight a folder and choose File ▸ Synchronize Folders. A new sync starts with a few questions, one per screen, and every button says what it does.

Six questions, then a review

Folders: the folder you highlighted is filled in; pick the other one with Browse…, which lists your places, bookmarks, drives, the network and saved servers. A swap button turns the direction round.

Goal, Deleting, Compare by, Leave out and Keep in sync follow, each with the recommended choice already selected and a sentence explaining every option.

The last step compares the folders and shows the list of changes, with the note that nothing has been changed yet. Name and save the sync there to run it again later.

Or every option on one page

The Advanced view shows the same choices in the same order on a single page: folders, goal, deleting, compare by, leave out and keep in sync. Switch between the two views at any time; a change in one shows in the other.

After a comparison the settings fold into one line, so the list of changes gets the room. Saved syncs open here, from the Open saved button.

Update, Mirror or Two-way

Pick what the sync should do. For Update and Mirror you also choose the direction: left to right, or right to left.

Update: copy new and changed files

Files that are new or newer in the source are copied to the target. Nothing is ever deleted, and a file that is newer in the target is not overwritten. The safe choice for a backup that only grows.

Mirror: make the target an exact copy

The target ends up identical to the source: new and changed files are copied, and files that are no longer in the source are removed from the target. On a local target they go to the trash by default.

Two-way: merge both ways

New, changed and deleted files go in both directions, so two copies of a project stay the same wherever you work. A file changed on both sides is a conflict: it is skipped until you pick which copy wins. The very first two-way run only merges and never deletes.

Conflicts are yours to decide

When a file changed in both folders, Two-way does not guess. The file is skipped and counted as a conflict, and it is reported again at every compare until you choose: copy it to the right, copy it to the left, or leave it alone.

The Conflicts filter lists only those files, with both sizes and dates side by side, so you can see which copy is newer before you pick.

Review the changes, item by item

The comparison is a folder tree with the left file, what will happen, and the right file side by side.

See what will happen, and change it

Clear icons show copy to the right or left, delete on either side, skip, no action, identical and conflict. A folder shows how many files it holds and what will happen to them; click it to fold or unfold.

Click an item's action to change it. On a folder, the choice applies to everything inside. Add to ignore list leaves a file or folder out of this sync for good and compares again.

Filter the list to only copies, only deletes or only skipped items, sort it by name, size, modified time or action, and open it in a large window with Expand. Clicking a row shows the full left and right paths.

Keep in sync while you work

Turn on Keep in sync and the first run works as usual: compare, confirm what will be applied, start. After that the app keeps an eye on both folders while it is open. Local folders are watched for changes and remote ones are checked at an interval; new changes are compared and applied for you.

Only safe changes are applied automatically. Conflicts, permanent deletes and large deletes stop and wait for your review.

Minimize the window to the Activity panel and keep browsing, during a one-time sync too. The status bar shows what the sync is doing, the Activity panel shows the amount done, speed, elapsed and remaining time, and Stop is one click away. There is no background service: syncing stops when you quit the app, and quitting while a sync is still running asks first.

Built not to lose your files

A sync tool deletes files for a living, so FileManagerUltra is careful about it.

Nothing changes until Start

Comparing only reads folder listings. Files are copied or deleted only after you have seen the list and pressed Start or Synchronize.

Deletes go to the trash

On local folders, removed files go to the trash by default, so you can restore them. Folders on another computer have no trash.

Permanent deletes ask first

Deletes that cannot be undone get their own warning dialog naming how many files and where, before anything is removed.

Guards against accidents

A Mirror that would delete more than half of the target, or a source folder that suddenly looks empty (an unplugged disk, a share that didn't mount), stops and asks instead of wiping the target.

File details come along

Modification times, permissions and other attributes are carried over as far as both sides support them. A detail that can't be set becomes a warning, never a lost file.

No passwords in profiles

Saved syncs store folder addresses only. Sign-in details stay in the app's connection store, and remote host keys are checked as usual.

Questions

Can I sync with an SFTP server or a network share?

Yes. Either folder can be local, on an SMB network share or on an SFTP server, and Browse… lists your saved servers. A server that isn't connected yet asks you to sign in right from the chooser.

Does it work on Linux, macOS and Windows?

Yes, Synchronize Folders is part of FileManagerUltra on all three, and folders are shown the way your system writes them (/home/you/Photos, C:\Users\you\Photos, \\nas\backup).

How does it decide that two files are different?

By default by size and modification time, which reads no file content and is fast. Small time differences (up to two seconds, as on FAT-formatted USB sticks) count as equal. You can also have it compare the content when size matches but the date differs, or always compare content when dates can't be trusted.

Can I leave out files such as node_modules or .git?

Yes. The Leave out step takes names and patterns (*.tmp, .git, node_modules). Left-out files are not compared and never deleted by a mirror. You can also add any item to the ignore list from its action menu.

Does it run on a schedule or in the background?

No. A sync runs when you start it, and Keep in sync works while the app is open. There is no scheduler or background service.

How is this different from a separate sync tool?

It lives in the file manager you already use, with the same connections, bookmarks and paths, and you can review the plan in a folder tree before anything happens. Dedicated tools such as FreeFileSync or rsync offer more automation; FileManagerUltra aims at the everyday case of keeping two folders in step, safely.

Is it free?

Yes. FileManagerUltra is open source under the Apache License 2.0, with no paid tier. It is in beta, so report anything that surprises you.
